# candidates 说明

这个目录专门存放小步快跑的候选稿，避免把根目录塞满。

建议每次只围绕一个目标做一组 `A/B/C`：

- `questionnewV2_1A.md`
  - 参数微调版，例如只改 `priorityPair lambda`
- `questionnewV2_1B.md`
  - 单题补丁版，例如重写 `Q18`
- `questionnewV2_1C.md`
  - 组合补丁版，例如 `Q18 + Q14`

每个候选稿都应在文件顶部或 `meta.note` 里注明：

- 修改目标
- 与基线相比改了哪些题 / 哪些参数
- 预期改善哪组高风险角色对
