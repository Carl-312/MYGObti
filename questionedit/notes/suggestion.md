我仔细分析了 V3 题库的 20 道题和主文档中的角色锚点坐标，从**轴覆盖分布、选项向量空间、角色可达性、角色可分离性**几个维度给你一个系统评估。

## 一、轴覆盖分布（Q1-Q16 主计分题）

| 轴线 | 主测题目 | 数量 |
| --- | --- | --- |
| 情感表达 | Q2, Q4, Q8, Q12, Q14 | 5 |
| 社交策略 | Q1, Q5, Q7, Q10, Q13 | 5 |
| 自我认知 | Q3, Q6, Q9, Q11, Q15, Q16 | **6** |

再加上 Q20（反向校验，也计分），自我认知轴实际有 **7 道计分题**，比其他两轴多 40%。

> **判断**：5/5/6 基本合理，但自我认知轴的权重偏高。由于余弦相似度看的是方向不是模长，这不会造成系统性偏差，但会导致**自我认知轴的测量噪声更低、分辨率更高**——也就是说，在该轴上位置相近的角色（如爽世 +0.7 vs 祥子 +0.9）更容易被区分，而其他轴上相近的角色（如乐奈 -0.2 vs 爽世 -0.1 在情感表达上）区分能力相对弱。

## 二、选项 Delta 结构分析

所有主测题都遵循统一的四级模板：

| 档位 | Delta 值 |
| --- | --- |
| 强负 | -0.7 |
| 弱负 | -0.3 |
| 弱正 | +0.3 |
| 强正 | +0.7 |

副轴扰动一律控制在 **±0.1**。

**优点**：

- 三轴高度正交，测量独立性好
- 每题正负对称，无方向性诱导

**隐患**：

- 缺乏 ±0.5 中间档——角色锚点中有不少**非极端值**（爱音情感 +0.3、睦社交 +0.2、爽世情感 -0.1），用户要模拟这些温和倾向时只能靠"混合选择"（一题选 +0.7 另一题选 -0.3），**信号较弱，容易被噪声淹没**
- 副轴 ±0.1 过于微弱，对于需要**跨轴联合判断**的角色区分帮助有限

## 三、角色可达性——每个角色都能被测到吗？

用余弦相似度匹配，关键是用户向量的**方向**能否指向每个角色锚点。我计算了各角色所在的八分体（octant）:

| 角色 | 情感 | 社交 | 自我 | 八分体符号 |
| --- | --- | --- | --- | --- |
| 高松灯 | - | - | - | (−−−) |
| 千早爱音 | + | - | - | (+−−) |
| 要乐奈 | - | - | + | (−−+) |
| 长崎爽世 | - | + | + | (−++) |
| 椎名立希 | + | + | + | (+++) |
| 三角初华 | + | + | - | (++−) |
| 若叶睦 | - | + | - | (−+−) |
| 丰川祥子 | - | + | + | **(−++)** ⚠️ |

**发现：爽世和祥子在同一个八分体 (−++)**，理论上无法通过纯坐标匹配区分。题库依赖 flag 机制（Q17 选 C、Q18 选 A 各 +0.1 boost）来分离，设计上是对的。但其余 6 个角色各占独立八分体，**向量方向上理论可达**。✅

## 四、角色可分离性——最关键的检验

我算了几组高风险角色对的余弦相似度（越接近 1 越难区分）：

| 角色对 | 余弦相似度 | 主要区分轴 | 风险等级 |
| --- | --- | --- | --- |
| **爽世 vs 祥子** | **0.895** | 社交（+0.8 vs +0.5） | 🔴 极高 |
| 灯 vs 睦 | 0.666 | 社交（-0.8 vs +0.2） | 🟡 中等 |
| 乐奈 vs 祥子 | 0.665 | 社交（-0.3 vs +0.5） | 🟡 中等 |
| 立希 vs 初华 | 0.549 | 自我认知（+0.6 vs -0.3） | 🟢 低 |
| 灯 vs 爱音 | 0.453 | 情感（-0.9 vs +0.3） | 🟢 低 |
| 乐奈 vs 爽世 | 0.343 | 社交+自我 | 🟢 低 |

### 具体问题：

**🔴 爽世 vs 祥子（cos = 0.895）**

仅靠 5 道社交策略题来分离 +0.8 vs +0.5 的差距，在 4 级 delta 体系下非常吃力。**两道 flag 题（Q17、Q18）每道只提供 +0.1 boost，总共最多 +0.2，恐怕不够翻转一个 cos=0.895 的匹配。** 建议：

- 提高 flag boost 到 +0.15~+0.2/题，或增加第三道 flag
- 或者直接在向量门控（vectorGate）阈值上做更严格的判定

**🟡 灯 vs 睦（cos = 0.666）**

区分点在社交策略轴（-0.8 vs +0.2）。5 道社交题能提供足够分辨率，但睦的社交得分 +0.2 极度温和——用户只需 5 题中有 3 题选弱负、2 题选弱正就可能偏到负侧被灯吸收。**睦是最容易"消失"的角色。**

**🟡 乐奈 vs 祥子（cos = 0.665）**

同样靠社交轴分离（-0.3 vs +0.5），乐奈社交 -0.3 也很温和。不过由于祥子走 flag 路径，实际上这对的压力没那么大。

## 六、改进建议

1. **引入 ±0.5 中间档 delta**：在 2-3 道题上把 ±0.3 改为 ±0.5，提升温和角色（爱音、乐奈、睦）的信号强度
2. **增强祥子 flag boost**：从 +0.1 提高到 +0.15~+0.2，或增加第 3 道隐藏 flag 题
3. **为睦增加 1 道"被动跟随"辨识题**：当前社交轴上睦的 +0.2 太容易被噪声淹没，可在 Q17-Q18 中嵌入一个针对"被动合作"的辅助 flag
4. **自我认知轴降 1 题**：考虑把 Q16 改为测情感表达或社交策略，使三轴更均衡（5/5/5 或 5/6/5）

整体来说这是一套**结构扎实、机制完备**的题库，主要短板在**温和锚点角色的区分度**上。修补 flag 机制和引入中间 delta 档位后，应该能显著提升匹配精度。
