# V2.1D 对比报告：tie-breaker 阈值 0.08 → 0.10

## 结论

- 推荐继续跟进：**D**。在所有目标指标上均优于 C，且没有引入任何可见的副作用。
- 评估配置：固定随机种子 `20260415`，Monte Carlo `100,000`，轻噪声 `1,200` 次/角色，pair-focused `800` 次/角色。

## 本轮改动

- `C`：冻结版 C（lambda 0.14 + Q18 latent 补丁 + Q14 主轴补丁），tie-breaker 阈值 `0.08`
- `D`：继承 C 全部内容，仅把 `enabledWhenTop2DiffBelow` 从 `0.08` 放宽到 `0.10`

## 逐项分析

### D 改善了什么

1. **pair-only accuracy +2.31%**：阈值放宽后，更多 0.08~0.10 区间的近平局被 latent 介入，爽世/祥子 pair 触发次数从 4,524 增加到 5,523（+22%），额外的 999 次介入带来了可测量的区分改善。
2. **full-model accuracy +1.75%**：在完整 8 角色模型中，爽世和祥子的回收也同步提升，说明阈值放宽没有让第三方角色"偷走"更多结果。
3. **双角色轻噪声回收各 +1.67%**：爽世 54.67%、祥子 55.17%，均创本轮新高。
4. **交叉误判下降**：爽世被误判为祥子 -1.25%，祥子被误判为爽世 -2.13%。

### D 没有伤到什么

1. **其他三组高风险角色对完全不变**（因为阈值变化仅在 top2 包含爽世/祥子时生效）。
2. **全局分布几乎无变化**：最大波动 0.06%，不构成任何角色消失或磁铁效应。
3. **tie-breaker 触发率 12.41%** 仍在健康区间（代码阈值：< 1% 太低，> 18% 太高）。

### 翻转率下降的解读

触发后翻转率从 28.93% 降到 25.32%，看似"变差"，实际是正常的：
- 阈值放宽后，新增的 trigger 案例位于 base gap 0.08~0.10 区间，基础差距更大，latent 更难翻盘
- 但这些案例中的一部分仍然被成功翻转，带来了净增益
- 总体翻转绝对次数从 2,931 增至 3,142（+211），实际翻转的总量反而更多

## 明确判断

- **D 优于 C**，建议替代 C 成为新的冻结版。
- 改动极为安全（纯参数、零题面变更），所有目标指标正向，无副作用。
- 后续若继续迭代，阈值 0.10 已经是比较接近上界的位置（再往上如 0.12 可能会让非目标 pair 也大量触发），不建议继续同方向推。
