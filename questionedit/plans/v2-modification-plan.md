## 1. 结论先行

V2 的推荐方向是：

- 主模型继续保持 `3D`
- 不把「规则感」升为第 4 主轴
- 引入 1 条只在平局附近介入的 `latent tie-breaker`
- latent trait 采用「控制/主导 ↔ 克制/服务」

这样做的原因很明确：

- 现有 3D 已经覆盖 8 角色中的 7 个独立八分体，主体结构没有坏
- 真正的结构性短板不是“轴不够多”，而是 `爽世 vs 祥子` 在 3D 中过近
- 「规则感」无法有效拉开爽世和祥子，因为两人都偏高
- 「控制/主导 ↔ 克制/服务」正好命中两人最核心的心理差异，且与现有 `社交策略` 轴基本正交

---

## 2. 当前 V1 的核心问题

### 2.1 主模型本身可用

当前三轴：

- 情感表达
- 社交策略
- 自我认知

已经能稳定区分大多数角色。问题不在“整体不可用”，而在“局部高混淆”。

### 2.2 真正的瓶颈是爽世 vs 祥子

两者当前都落在 `(−++)` 八分体，意味着：

- 情感表达都偏负
- 社交策略都偏正
- 自我认知都偏正

所以仅靠 3D 主向量，很容易出现 top2 过近。

### 2.3 「规则感」不是这对角色的有效补刀维度

若加入「规则感（自由散漫 ↔ 责任/秩序驱动）」：

| 角色 | 规则感预估 | 判断 |
| --- | --- | --- |
| 爽世 | 高 | 会定框架、控流程、维持秩序 |
| 祥子 | 高 | 高自律、关系服务流程化、压抑自我去符合应然 |

结论：

- 这条轴对 `乐奈 vs 爽世`、`乐奈 vs 祥子` 这类组合有解释力
- 但对 `爽世 vs 祥子` 几乎无效
- 而 `乐奈 vs 爽世` 本来就不是当前最难分的一组

因此，V2 不建议把“规则感”作为主要补强方向。

---

## 3. V2 目标架构

## 3.1 保持 3D 主模型

V2 仍使用：

- `emotionExpression`
- `socialStrategy`
- `selfRecognition`

主结果仍由 3D 用户向量与角色锚点的余弦相似度决定。

## 3.2 新增 1 条 latent trait

latent trait 定义为：

`controlServiceOrientation = 控制/主导(+1) ↔ 克制/服务(-1)`

它不是主轴，不参与常规角色匹配，只在 tie-break 阶段介入。

## 3.3 latent trait 的作用范围

推荐只在以下条件下触发：

1. `top2CosDiff < 0.08`
2. top2 候选中包含 `爽世` 或 `祥子`

可选扩展：

- 若后续数据表明 `睦`、`初华`、`立希` 也在此轴上有稳定分离价值，再扩大适用范围

---

## 4. 为什么选「控制/主导 ↔ 克制/服务」

这条轴测的不是“你参不参与”，而是“你参与时，站在什么心理位置上”。

### 4.1 与社交策略轴的分工

| 维度 | 问题本质 |
| --- | --- |
| 社交策略 | 你会不会主动介入关系与局面 |
| 控制/服务 latent | 你介入时是为了掌控，还是为了承担、照顾、服务 |

### 4.2 对核心角色的解释力

| 角色 | latent 预估值 | 解读 |
| --- | --- | --- |
| 爽世 | +0.8 | 介入是为了控局、安排、把局势拉回自己能管的位置 |
| 祥子 | -0.7 | 介入是为了兜底、服务、压住自我需求去维持关系运作 |
| 立希 | +0.5 | 有明显把自己的判断推向他人的倾向 |
| 初华 | +0.3 | 以帮忙为名介入，但带一定推土机味道 |
| 睦 | -0.5 | 更接近顺从、配合、低姿态承担 |
| 灯 | -0.3 | 不控局，但偶尔会以退让方式承受关系压力 |
| 爱音 | -0.1 | 更偏表面讨好与自保，中性偏服务 |
| 乐奈 | 0.0 | 既不热衷控制，也不主动做情绪劳动 |

### 4.3 对爽世 vs 祥子的价值

这两人在此轴上的预估差距可达 `1.5` 左右，远高于三维主轴中的任何单轴差距。

这意味着：

- 它不是“再加一点辅助信息”
- 而是“专门为当前最难分的角色对补上一条强区分维度”

## 5. 题库结构调整建议

## 5.1 推荐的 20 题结构

推荐在不增加用户显性感知负担的前提下，重排为：

- `Q1-Q16`：3D 主计分题
- `Q17-Q19`：3 道 latent 题
- `Q20`：反向校验题

对应变化：

- 保留当前 16 道主测题的主体结构
- 将现有 `Q17/Q18` 从“祥子 flag”升级为真正测量 latent 的题
- 新增 1 道 `Q19` latent 题
- 取消独立注意力检测题，改为被动质量检测

## 5.2 为什么建议移除独立 attention check

当前 `Q19` 的荒谬选项虽然简单，但只有一个粗糙信号，收益有限，却占掉了最宝贵的 1 个题位。

V2 更推荐改成被动检测：

- 总作答时长过短
- 连续多题选项位置完全一致
- `Q6/Q20` 反向校验冲突
- 主轴答案异常极化

只有同时命中多个条件时，才标记 `possibleCarelessResponse=true`。

这样比单道荒谬题更稳，也能腾出 1 题给真正有区分价值的 latent 测量。

## 6. latent 题的设计原则

latent 题不要写成“你是不是控制狂 / 你是不是奉献型”的直球提问，而要写成：

- 同样都参与局面
- 但参与动机不同
- 一个选项偏“接管”
- 一个选项偏“兜底”
- 一个选项偏“协商”
- 一个选项偏“抽离”

推荐的四档可使用：

| 档位 | latent delta |
| --- | --- |
| 强服务 | `-0.8` |
| 弱服务 | `-0.3` |
| 弱控制 | `+0.3` |
| 强控制 | `+0.8` |

为避免与主轴污染：

- latent 题不计入 3D 总向量
- 只单独累计 `latentScore`
- 文案不直接出现“控制”“服务”“牺牲”“权力”等高提示词

## 7. 对现有 Q17/Q18 的改造方向

## 7.1 Q17：从“空间审美偏好”改为“经营方式偏好”

当前版本更接近氛围偏好，不足以直接测量心理动机。

建议改成：

- 同样是经营一个空间
- 差别不在“热闹还是安静”
- 而在“我要不要把秩序握在手里”“我要不要让自己当那个兜底的人”

目标区分：

- 强控制：主动设规则、安排流程、确保一切按自己的框架运行
- 强服务：维持空间运转与他人舒适，但尽量不把自己推到权力位

## 7.2 Q18：从“被夸替人着想”改为“承担关系劳动时的内在动机”

当前版本已经很接近可用，但还偏祥子特征 flag。

建议升级为：

- 不是测“你像不像祥子”
- 而是测“当你付出时，你是在换取掌控、换取确认，还是单纯兜底”

这样能把：

- 爽世式的“我来接手，因为别人不靠谱”
- 祥子式的“我来承担，但不一定要求主导位置”

拆开。

## 7.3 新增 Q19：专门写一题“介入同一局面，但姿态不同”

推荐场景类型：

- 小组快失控，没人愿意接
- 有人情绪崩了，但事务还得继续
- 活动快迟到，现场必须有人兜住

重点不是“你做不做”，而是：

- 你是站到台前接管
- 还是站到后场收拾

## 8. 评分与 tie-breaker 逻辑

## 8.1 主模型评分保持不变

```ts
baseScore(character) = cosine(user3DVector, character.anchor3D)
```

## 8.2 latent 分数单独累计

```ts
latentScore = mean(Q17, Q18, Q19)
```

范围建议归一化到 `[-1, 1]`。

## 8.3 只在接近平局时介入

```ts
if (top2CosDiff >= 0.08) {
  return top1
}
```

若进入 tie-break：

```ts
latentMatch(character) = 1 - abs(latentScore - character.latentAnchor)
finalTieScore(character) = baseScore(character) + lambda * latentMatch(character)
```

推荐参数：

- 常规 tie-break：`lambda = 0.08`
- 若 top2 恰好为 `爽世/祥子`：`lambda = 0.12 ~ 0.15`

## 8.4 不建议继续使用“单向 boost”

V1 的 `flagBoost` 本质上是“只给祥子加分”，这会产生两个问题：

- 机制解释力弱，看起来像硬触发
- 无法同时刻画爽世和祥子的对向差异

V2 应改成：

- 同一条 latent 轴上两端都可得分
- 用对称的角色锚点解释结果

这样算法更自然，也更好调参。

## 10. 执行顺序

## Phase A：先改模型说明

1. 更新 `meta`，从 `hiddenRoleRule + flagBoost` 改为 `latent tie-breaker`
2. 为 8 个角色补全 `controlServiceOrientation` 预估锚点
3. 保留 3D 主模型不动

## Phase B：再改 3 道 latent 题

1. 重写 `Q17`
2. 重写 `Q18`
3. 新写 `Q19`

要求：

- 不写成角色彩蛋题
- 不让用户一眼看出“哪项最高级”
- 四个选项都应有体面动机

## Phase C：最后改前端判定逻辑

1. 先算 3D base cosine
2. 判断 `top2CosDiff`
3. 若未进入阈值，直接出结果
4. 若进入阈值，再计算 latent 重排
5. 输出结果页时可展示一句弱解释文案，但不要把 latent 轴显性暴露成“第 4 维”

## 11. 验证标准

V2 是否成功，不看“理论上更优雅”，而看以下结果：

### 11.1 算法指标

- `爽世 vs 祥子` 的误判率明显下降
- `top2CosDiff < 0.08` 的样本中，重排后用户自认同率上升
- 其余 6 个角色的稳定性不被明显破坏

### 11.2 体验指标

- 用户不会感觉题目突然多了一套“职场人格测试”
- latent 题仍保持 MyGO 气质和人际张力
- 结果解释能让用户觉得“是这个味”，而不是“硬做隐藏门”

### 11.3 校准方式

建议找 8-12 名深度粉丝小规模试测：

- 先让他们主观选择“我最像谁”
- 再跑 V1 / V2 两版结果对比
- 重点看 `爽世/祥子`、`睦/灯` 的识别满意度

---

## 12. 最终建议

V2 最应该做的，不是把模型从 `3D` 强行扩成 `4D`，而是：

- 维持 3D 主结构的简洁性
- 用 1 条强针对性的 latent trait 修补最难分的角色对
- 把“单向隐藏角色加分”升级成“对称的心理动机重排”

一句话总结：

> V2 的方向应当是 `3D 主模型 + 控制/服务 latent tie-breaker`，而不是 `3D + 规则感`。
