# Phase 02.1-01 Summary

**Lightweight workspace migration completed with a shared quiz-core package and a minimal Fastify API baseline**

## Accomplishments

- Moved the React + Vite app from the repo root into `apps/web` without breaking the current build path.
- Established `apps/api` as a separate Fastify + TypeScript package with a minimal `/api/health` route and standalone scripts.
- Extracted quiz contracts, cosine similarity, and result evaluation into `packages/quiz-core`, leaving only one source of truth for shared domain logic.
- Removed the former web-local copies of quiz types and matching logic so the new shared package is the canonical implementation.

## Decisions Made

- Kept the Markdown raw import inside `apps/web/src/entities/quiz/model/canonicalQuiz.ts` for this step only, because API-driven canonical parsing belongs to `02.1-02`, not `02.1-01`.
- Refactored `evaluateQuizResult` to accept `tieBreakerRule` as input instead of importing browser-side canonical metadata directly.
- Used npm workspaces plus per-package `package.json`/`tsconfig.json` files as the smallest workable monorepo shape for this codebase.
